# Khedma Taktak

Plateforme de recrutement — projet vierge Angular + Spring Boot.

## Structure

```
khedma-taktak/
├── backend/    Spring Boot 3.3 (Java 21)
└── frontend/   Angular 22
```

## Démarrage

### Backend

```bash
cd backend
./mvnw spring-boot:run
```

API : http://localhost:8080/api/health

### Frontend

```bash
cd frontend
npm install
npm start
```

App : http://localhost:4200
